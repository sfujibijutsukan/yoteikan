# 現在時刻とiPhoneウィジェット

## アプリの現在時刻

今日の時間割に赤い線・丸・時刻ラベルを表示します。通常の計画画面、空きをたたんだ計画画面、1日表示で、それぞれの時間軸に合わせた位置を使います。線は操作を受け取らず、付箋の移動や伸縮を妨げません。

起動時・アプリへ復帰したとき・「今日」を押したときは現在時刻が見える位置へ移動します。その後の時計更新だけではスクロールを動かしません。表示は30秒ごとに更新し、日付が変われば今日を表示中の時間割も翌日へ切り替えます。他の日には線を出しません。計画時間帯より前・後の場合は線を出さず、時間帯の先頭・末尾へ移動します。

## ホーム画面へ追加

1. 対応版の予定館をiPhoneへインストールし、一度開きます。
2. ホーム画面を長押しし、ウィジェットを追加する画面で「予定館」を探します。
3. 「今日の予定」の小サイズか中サイズを追加します。

現在時刻前後の計画を、時間軸と色付きの予定ボックスで表示します。小サイズは現在の約15分前〜45分後、中サイズは約30分前〜90分後が目安です。計画の時間帯の端では表示範囲を調整し、時間帯の外にいる場合は現在時刻の線を出しません。終了済みの予定は薄く表示します。短い予定には文字を表示する高さを確保し、ボックスが重なる場合は列を分けます。

配置済みの付箋に加え、アプリで選択済みのカレンダーから読み込んだ時刻付きの固定予定も表示します。アプリで別の日を開いていても、ウィジェットは今日の時間割を表示します。未配置の付箋・詳細メモ・終日予定は含めません。固定予定のキャッシュはアプリの起動・復帰、カレンダーの読み直し・選択変更時に更新します。外部カレンダーの変更が見えない場合はアプリを一度開いてください。

タップすると今日の計画画面を開き、現在時刻へ移動します。予定の編集・配置・削除に応じて更新を要求します。24時間先まで5分ごとの表示データを用意しますが、実際の更新タイミングはiOSが管理するため、秒単位の時計や常時の即時更新ではありません。保存済みの翌日の予定も、アプリを開かずに表示できます。まだ共有データを読み込めない場合は起動案内を表示します。

## 開発・署名

- ウィジェット拡張：`YoteikanWidget`、バンドルID `org.sfuji.yoteikan.widget`。
- アプリと拡張のApp Groups：`group.org.sfuji.yoteikan`。同じ開発チームを指定し、このグループを両ターゲットのSigning & Capabilitiesで有効にします。実機用プロファイルも両方に必要です。
- アプリのiOS用entitlementsと拡張のentitlementsへ設定済みです。チームをリポジトリへ固定しません。開発者アカウントでのグループ登録やプロファイル更新は、このコード変更だけでは完了しません。
- App Groupsは同じiPhone内のアプリと拡張のデータ共有に使います。iCloud・端末間同期は追加していません。
- JSONを共有コンテナーへ原子的に保存します。拡張が生成する各表示データには必要な2日分だけを渡し、保存済みの過去・未来の計画は削除しません。メモ本文は含めず、アプリ本体の従来の保存キーとデータ形式は維持します。共有先に書けない場合もアプリ側の予定は保存されます。
- iPhone/iPad向け拡張のみを同梱します。Mac Catalystビルドでは拡張を組み込みません。
- `--demo` は実データ用の共有領域を書き換えません。DEBUGシミュレーターの `--widget-gallery` は拡張と同じ表示部品を使う検証画面です。ホーム画面そのもののスクリーンショットとは区別します。追加の `--widget-publish-test` はシミュレーター用のサンプルを共有先へ保存し、拡張機能が実際に読み込めることを確認するテスト専用引数です。通常のデモ・Release版では実行しません。
