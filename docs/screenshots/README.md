# スクリーンショット

iPhone 17eシミュレーター / iOS 27.0でXCTestを使って実際に操作し、2026年10月23日に撮影しました。デモ表記付きの画面はサンプル計画、カレンダー画面はEventKitに登録した検証用予定です。

Issue #4の色名設定・名前付きの色選択に対応した画面です。Issue #1の移動つまみ、Issue #2の表示整理、Issue #3の日付スワイプも含みます。
