# Issue #17：予定の通知

配置した付箋にローカル通知を追加。初期値は5分前で、付箋の編集から0〜1440分前（1分単位）または通知なしを選べます。0分は開始時刻です。旧データは5分前として読み込み、通知なしは明示的なnullとして保存します。

通知許可は付箋編集または下部の設定から要求します。拒否された場合はiPhone設定への導線を表示します。カレンダーの固定予定はカレンダー側の通知設定を使い、重複する通知をアプリから追加しません。プリセットから作成する付箋は5分前になります。

全日付の保存済み付箋から未来の通知を時刻順に最大60件予約します。未配置・通知なし・通知時刻が過去の予定は予約しません。予定の移動、名前変更、削除、未配置、Undo、アプリへの復帰時に更新します。同じ付箋の識別子を使い、予約の差し替えを直列化して古い編集結果が残らないようにします。アプリが閉じていてもOSへ予約済みの通知は配信対象になります。長期間アプリを開かない場合、60件より先の通知は次回起動時に補充されます。表示・音はiPhoneの通知設定や集中モードにも従います。

実装はAppleの[ローカル通知の予約](https://developer.apple.com/documentation/usernotifications/scheduling-a-notification-locally-from-your-app)と[予約一覧の取得](https://developer.apple.com/documentation/usernotifications/unusernotificationcenter/getpendingnotificationrequests(completionhandler:))に基づき、UserNotificationsを使用します。

検証：旧データ・通知なしの保存、時差と日付跨ぎ、過去・未配置の除外、件数制限、予約変更・取消・権限拒否・失敗後の再試行をユニットテストで確認。シミュレーターで許可・通知予約件数・個別設定の保存を確認します。実機の配信・音・集中モードは未確認です。
