# アプリ設計

## 目的と基本方針

朝に今日やることを選び、カレンダーの空き時間へ付箋を1枚ずつ配置して、1日の時間割を組み立てる。日中に予定が変わっても、紙の付箋のように自分で組み替えられる。

- 付箋は「内容＋所要時間」で作る。開始時刻は配置時に決まる。
- 1枚の移動・伸縮が、ほかの付箋や固定予定を変更しない。
- 組み替え途中の重なりを許可する。警告で操作を中断しない。
- プリセットはひな形。追加した今日の付箋を変更しても、ひな形は変わらない。
- カレンダーは既存予定を確認するための読み込み専用とする。

## 画面構成

時間割の＋／−で1・2・4・8倍を選ぶ。1倍は1分あたり1.55ポイント、8倍では5分枠が62ポイントとなる。4倍以上では5分ごとの補助目盛りを表示する。全日表示から戻ると最後の拡大率を復元する。拡大率変更時は選択した予定、選択がなければ現在表示中の時間帯を基準にする（時間単位）。拡大率は画面内の状態として保持し、再起動時は1倍。

予定の描画高さは時間枠から間隔を差し引いた値とし、短い予定にも最低高さを強制しない。文字・枠線・操作つまみは枠内に収める。44ポイント未満では1行のタイトル、14ポイント未満では色のみとし、縮小時の内容は選択・詳細で確認できる。伸縮つまみは高さ54ポイント以上、選択中の移動つまみは32ポイント以上で表示する。伸縮の途中で小さくなった場合は、指を離すまで操作を継続する。実際に時刻が重なる予定は従来どおり並列に配置する。カレンダーの固定予定も同じ高さの規則に従う。

| 領域 | 内容 |
|---|---|
| ヘッダー | 計画の時間帯、色の名前設定、カレンダー設定、日付切り替え、今日へ戻る |
| 計画の目安 | 空き時間と未配置時間を2本の横棒と小さな時間表示で表す |
| 終日予定 | 時間割の上部に表示し、空き時間は減らさない |
| 左：時間割 | 固定予定と配置済み付箋。付箋の高さで所要時間を表す |
| 中央：詳細メモ | 選択中の付箋のメモ。編集・保存に対応 |
| 右：付箋 | 今日の未配置・時間外の付箋。縦スクロールで貯め、プリセット追加・新規作成 |
| 下部操作 | 元に戻す、詳細メモ、選択中の付箋の編集・未配置への戻し |

縦画面は左の時間割と右の付箋の2ゾーンを基本にする。利用可能な幅が700ポイント以上なら中央の詳細メモを追加し、3ゾーンを横並びにする。iPhoneは左右の横画面にも対応する。狭い画面では下部の詳細メモボタンから同じメモを別画面で開く。

右の領域は見出しの「付箋／詳細」でワンタップ切り替えする。付箋をタップしても選択と同時に詳細へ切り替える。配置済みの付箋はタップで選択し、「詳細」ボタンでその予定を表示できる。未選択の場合はその日の最初の配置済み付箋、なければ未配置の付箋を選ぶ。予定がない場合は選択を促す表示を出す。

詳細は付箋名・開始終了時刻・所要時間・メモ・編集ボタンで構成する。「付箋」に戻すと右の一覧を再表示する。横画面で詳細を右に表示する際は中央メモを隠して重複を避ける。詳細の表示中も右へのドロップを受け付け、未配置へ戻した後は付箋表示に戻す。

中央・右・別画面のメモは選択中の付箋に紐づく。下書きは表示の切り替えや付箋の選び直しでも保持し、「メモを保存」で端末に保存する。メモの変更は予定時刻・所要時間・プリセットを変えず、Undoに対応する。保存前の下書きは再起動で破棄する。

## 操作と制約

画面上部にアプリ名の見出しは置かず、時間帯・色・カレンダーの操作を残す。空き時間と未配置時間の棒は、設定した計画時間全体を共通の基準とする。空き時間は固定予定と配置済み付箋の占有時間を差し引き、未配置時間はその日の未配置付箋を合計する。未配置が計画時間を超える場合は棒を全幅で止め、時間の数値は実際の合計を表示する。0分の棒は背景のみとなる。

日付移動・今日・時間帯・色・カレンダーを高さ44ポイントの1行にまとめる。曜日は短い表記とし、設定ボタンの円形背景を省く。時間のグラフはその下の2本にまとめ、全日表示は時間割の拡大率操作列へ移す。デモ表記は時間割の見出しに添える。右の付箋／詳細切り替えと同じ高さで操作列を揃え、下部バーも上下余白を減らす。操作を隠すことなくタイムラインの縦幅を確保する。

| 操作 | 結果 |
|---|---|
| 未配置の付箋を長押しして時間割へドラッグ | 所要時間を保ったまま配置 |
| 配置済みの付箋を選択し、右上の↕をドラッグ | 長押しを待たず、所要時間を保ったまま開始時刻を変更 |
| 配置済みの付箋を長押しして上下にドラッグ | 文字のない余白も含めた付箋全体から開始時刻を変更 |
| 付箋の下端をドラッグ | 開始時刻を保ったまま延長・短縮 |
| 右の付箋ゾーンへドラッグ、または未配置に戻すボタン | 開始時刻を外し、内容と所要時間を保持 |
| 元に戻す | 直前の付箋・プリセット・色名の変更を1段階戻す |
| プリセットをタップ | その日向けの独立した付箋を追加 |
| 日付欄・タイムラインの余白を左右スワイプ | 左で翌日、右で前日へ移動 |

計画範囲の初期値は5:00〜24:00。時計ボタンから開始・終了を0:00〜24:00の中で1時間単位で選び、全日共通で保存する。開始より後の終了だけを選べるため、最短1時間、最長24時間。日付をまたぐ時間帯は扱わない。保存前のキャンセルと保存後のUndoに対応する。

時間軸、1日全体の縮尺、空き時間、編集画面の範囲表示は保存されたPlanningHoursを共通で参照する。設定した時間帯から、範囲内の付箋と固定予定が占める時間を重複なく差し引く。境界をまたぐ予定は見える部分だけを表示・集計する。

時間帯を狭めても既存の付箋・プリセットの時刻や所要時間は変えない。完全に範囲外の付箋は右のゾーンに「時間外」と元の開始時刻付きで表示し、編集やドラッグで再配置できる。範囲を戻すと元の位置に表示する。時間帯より長い付箋の配置は説明を表示して止め、勝手に短縮しない。移動・伸縮は5分刻みで、終了は設定した境界を超えない。

重なる予定は連続して重なり合うグループに分け、グループ内で列を割り当てる。重なった付箋には枠線を付け、並列の配置で関係を示す。読み上げ用にも重なりのヒントを付ける。空き時間の計算は、重複した時間を二重に差し引かない。

移動中は開始・終了時刻を表示する。右上の↕は移動用、下端のつまみは伸縮用として操作領域を分ける。配置した直後にも移動つまみを表示し、編集画面を開かずに時間を変更できる。

「1日を見る」では全体の配置を確認し、「拡大する」で細かい操作へ戻る。移動つまみは拡大表示で使用する。

日付スワイプは日付欄とタイムラインの背景で受け付ける。付箋上の移動・伸縮、右の付箋ゾーンの縦スクロールとは操作領域を分ける。縦方向や短いドラッグでは日付を変えない。日付を変更すると、その日の付箋とカレンダー予定を再表示する。

## 表示の方針

Issue #2では、常設の説明文よりも配置・色・アイコンで状態と操作を伝える構成に整理した。

- ヘッダーはアプリ名・日付・カレンダー設定を中心にし、コピー文や英語名の重複表示は置かない。
- 固定予定は落ち着いた色と鍵アイコンで区別し、「カレンダーの予定」という補足は繰り返さない。
- 配置済みの付箋は開始・終了時刻と高さで時間を示し、所要時間を重ねて表示しない。未配置の付箋の所要時間は残す。
- 未配置エリアは見出し・枚数・枠で示す。空のときもドラッグで戻せる場所を維持する。
- プリセットは名前・所要時間・追加ボタンを同じ行に置き、追加した枚数も行内で返す。
- カレンダー設定は選択肢を中心に表示する。読み込み専用と権限に関する情報、エラー、フォームの項目名は残す。
- 操作方法の詳細はREADMEと開発文書にまとめ、画面内に常設の説明を並べない。

## データモデル

| 型 | 主な項目 | 役割 |
|---|---|---|
| Sticky | id、title、minutes、tone、memo、day、start | 日付に属する付箋。startがnilなら未配置 |
| Preset | id、title、minutes、tone、memo | 日付や開始時刻を持たないひな形 |
| FixedEvent | id、title、start、end、allDay | カレンダーから読み込んだ予定 |
| StickyColor | id、name、hex | 色の識別子、表示名、RGBカラーコード |
| SavedPlan | stickies、presets、colors、hours | ローカル保存の単位 |
| PlanningHours | start、end | 全日共通の開始・終了。日付内の分数で保存 |
| TimelineItem / TimelineSlot | 開始・終了、列番号・列数 | 重なりのレイアウト計算 |

時間は日付内の分数で扱い、日付は端末のローカル日付をキーとする。付箋とプリセットはCodableでシリアライズし、UserDefaultsのyoteikan.plan.v1へ保存する。表示対象のカレンダーIDはcalendar.enabledへ保存する。

色の初期値は「準備・仕事・生活・休憩」の4色。パレット画面で色と名前を追加・編集・削除し、付箋とプリセットの色選択に表示する。追加数に固定の上限は設けず、選択画面は折り返して表示する。日付によらず共有し、付箋の内容・所要時間・配置を変えない。濃い色の付箋には白い文字を使う。

各色に配列の位置とは独立した整数IDを持たせ、Sticky / PresetのtoneはそのIDを参照する。削除時は残す色を選択し、全日付の付箋と全プリセットを付け替える。続けて複数色を削除した場合も付け替え先を引き継ぐ。最後の1色は削除不可。保存時に前後の空白を除き、空の名前と不正な6桁RGBコードでは保存できない。保存前は画面内の下書きとし、キャンセルで破棄する。保存・付け替えを1回の変更として記録し、Undoで色と参照をまとめて復元する。

以前のcolorNames配列は初期4色へ移行し、名前・付箋・プリセットを保持する。colorNamesもない初期版は初期色で補う。削除後の色IDも保存・復元し、存在しない色への参照は最初の色で補正する。設定は端末内へ保存し、再起動後も保持する。

カレンダー予定はローカルの計画データへ複製保存せず、EventKitから再取得する。Undoの履歴はメモリ内に保持し、アプリの再起動をまたいでは保持しない。

hoursのない旧データや不正な時間帯は5:00〜24:00を補い、付箋・プリセット・色の設定を保持する。

## 実装の役割分担

| ファイル | 役割 |
|---|---|
| YoteikanApp.swift | アプリの起動と状態の共有 |
| Models.swift | データ型、保存・Undo、スナップ・重なり・空き時間の計算 |
| CalendarStore.swift | カレンダー権限、表示対象の選択、予定の取得・更新 |
| PlannerView.swift | タイムライン、ドラッグ・伸縮、未配置エリア |
| Editors.swift | 付箋・プリセットの作成編集、名前付きの色選択、色名・カレンダー設定 |

SwiftUIの状態管理とPlanStore / CalendarStoreで構成し、バックエンドは置かない。補助ツールにはGoを使用する。

## カレンダー連携

iOS 17以降のEventKitのフルアクセスを要求する。読み込みにフルアクセス権限が必要だが、通常動作ではカレンダーへの追加・変更・削除を行わない。権限を拒否した場合でも、付箋による計画は利用できる。

表示するカレンダーを選択できる。終日予定は別枠に表示し、日をまたぐ予定はその日内の範囲へ切り詰める。カレンダーの変更通知、アプリの復帰、表示日付の変更時に再取得する。会議が動いて付箋と重なっても、付箋は自動で移動しない。

Debugのシミュレーター限定で、UIテスト用のカレンダーを作成する処理を持つ。通常起動・実機・Releaseでは、このテスト用の書き込みを行わない。詳細は[開発・検証手順](development.md)を参照。

## 初期版の範囲

端末間同期、バックアップ・書き出し、通知、カレンダーへの書き出し、繰り返し付箋、後続予定の自動移動は含まない。データは端末内に保存し、アプリの保存データを消すと計画も消える。
