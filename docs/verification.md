# 動作確認

2026年10月23日。iPhone 17eシミュレーター / iOS 27.0で確認しました。

初期版をSwiftUIで実装し、Issue #3の改善後、ユニットテスト6件・UI操作テスト11件の計17件がすべて成功しました。スクリーンショット抽出・一覧作成ツールはGoで実装しています。Pythonへの依存はありません。

## Issue #3：左右スワイプで日付を移動

[Issue #3](https://github.com/sfujibijutsukan/yoteikan/issues/3)は、Issue #1・#2を引き継いだ fix/issue-3-swipe-day-navigation ブランチで対応しました。

- 日付欄とタイムラインの余白で、左スワイプは翌日、右スワイプは前日へ移動。
- 付箋の移動・伸縮と未配置エリアの横スクロールは、日付スワイプとは別の領域で操作。
- 日付欄・余白の両方から移動し、戻った日の付箋の時刻と所要時間が保たれることを確認。
- 縦スクロールと未配置エリアの横スクロールで、日付が変わらないことを確認。

既存の15件と日付スワイプのUIテスト2件、計17件が成功しました。

検証用の終日予定が2日間で作成されていたため、当日1日分に修正しました。カレンダー接続・選択・日付スワイプの3件を再実行し、翌日に前日の付箋・会議・当日限定の終日予定が表示されないことも確認しました。通常のカレンダー読み込み処理は変更していません。

## Issue #2：説明文と補足ラベルの整理

[Issue #2](https://github.com/sfujibijutsukan/yoteikan/issues/2)は、Issue #1の操作改善を引き継いだ fix/issue-2-simplify-interface ブランチで対応しました。

- 主画面のコピー文、英語名の重複表示、操作説明フッター、集計欄の補足を整理。
- 固定予定の「カレンダーの予定」、開始・終了時刻から分かる所要時間の重複表示を削除。
- 重なりは枠線と並列表示で示し、常設の説明バナーを削除。読み上げ用のヒントは保持。
- 未配置エリアを見出し・枚数・枠で示し、空のときもドラッグで戻せる領域を維持。
- プリセットの操作説明・追加完了の文章を削除し、追加枚数を行内に表示。
- カレンダー設定を選択肢中心に整理。読み込み専用・権限・エラーの情報は残す。
- フォームの項目名と必要な時間の範囲を残し、重複する説明だけを短縮。

全15件のテストで、移動・伸縮・Undo・保存・プリセット追加・カレンダー選択を再確認。主画面、編集、プリセット、カレンダー設定のスクリーンショットを目視確認しました。

## Issue #1：配置後の開始時刻変更

[Issue #1](https://github.com/sfujibijutsukan/yoteikan/issues/1)では、追加した付箋の開始時刻をドラッグで変更する操作を改善しました。

- 旧版で、追加直後の付箋の余白を長押ししても開始時刻が変わらないケースをUIテストで再現。
- 付箋全体に操作領域を設定し、文字のない部分からも長押しで移動できるよう修正。
- 選択した付箋の右上に移動つまみを表示。長押しを待たずに上下ドラッグで移動できる。
- 移動中は開始・終了時刻を表示し、下端の伸縮つまみと操作領域を分離。
- 新規作成→配置→30分移動の操作、60分の所要時間保持、Undo、再起動後の保存を確認。
