# 動作確認

2026年10月23日。iPhone 17eシミュレーター / iOS 27.0で確認しました。

初期版をSwiftUIで実装し、ユニットテスト6件・UI操作テスト7件の計13件がすべて成功しました。スクリーンショット抽出・一覧作成ツールはGoで実装しています。Pythonへの依存はありません。

## 確認した動作

| 項目 | 結果 |
|---|---|
| 付箋を内容・所要時間付きで作成 | 成功 |
| 未配置から時間割へドラッグして配置 | 成功 |
| 9:00の付箋を9:30へ移動 | 成功。ほかの付箋は移動しない |
| 60分の付箋を下端のドラッグで90分へ延長 | 成功。カレンダーの固定予定はそのまま |
| 予定との重なり | 許可し、色付きの枠線とメッセージを表示 |
| 複数・連鎖する重なりの表示 | 独立した列を割り当てる処理を確認 |
| 下部へドラッグして未配置へ戻す | 成功。所要時間を保持 |
| ボタンから未配置へ戻す、元に戻す | 成功 |
| プリセットから追加、新しいプリセットを作成 | 成功。今日の付箋とプリセットは別データ |
| 保存、アプリ再起動、編集を元に戻す | 成功 |
| 日付の切り替え | その日だけの付箋を表示 |
| カレンダーから固定予定と終日予定を読み込む | 成功。EventKitに登録した検証用予定で確認 |
| 表示対象のカレンダーをオン・オフ | 予定の表示・非表示に反映 |
| 1日全体の表示 | 6:00〜24:00を一覧表示 |

カレンダーのアクセス許可操作もシミュレーターで確認しました。通常動作は読み込み専用です。シミュレーター限定のテスト用処理で「予定館・動作確認用」カレンダーと検証用予定を作成しています。デモ表示のある画面はサンプル計画です。
