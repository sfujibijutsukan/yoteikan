# Issue #23：サイドバーの位置

歯車の「アプリ設定」から「サイドバーの位置」を左・右で選択できます。初期値は右で、選択はその場で反映し、アプリを再起動しても保持します。

縦画面は「サイドバー／時間割」または「時間割／サイドバー」の2ゾーンです。横画面の付箋表示では「付箋／詳細メモ／時間割」または「時間割／詳細メモ／付箋」となります。サイドバーを詳細に切り替えた場合も選択した側を使用します。

同じ識別子のゾーンを並べ替えるため、表示位置を変えても選択やメモ下書きを保持します。ドラッグの判定には各ゾーンの実際の画面位置を使い、左右のどちらからでも配置・未配置への戻しができます。予定の時刻・長さ・通知設定は変更しません。表示位置は端末内の設定で、予定のUndoとは分けて保存します。

検証：左右の位置、詳細への切り替え、左から時間割へのドラッグ、左への戻し、横画面3ゾーン、再起動後の保持、右への復帰をUIテストで確認。従来の右サイドバーの基本画面と横画面も再確認します。実機は未確認です。
