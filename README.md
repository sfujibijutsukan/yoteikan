# 予定館 / Yoteikan

朝に1日の予定を組み立てる、iPhone用のタイムボクシングアプリです。カレンダーの固定予定を土台に、「読書・30分」のような付箋を空き時間へ配置します。

<img src="docs/screenshots/18-two-zone-planner.png" width="300" alt="左に時間割、右に付箋と詳細の切り替えがある予定館">

## できること

- 内容・所要時間・色・メモ付きの付箋を作成。
- 左の時間割・右の付箋置き場で操作。横画面では中央に詳細メモを表示。
- 色と名前を自由に追加・編集・削除。付箋とプリセットで共通利用。
- 長押しドラッグで配置し、選択後は右上の↕をドラッグして開始時刻を変更。下端のつまみで延長・短縮。
- 変更するのは触っている1枚だけ。ほかの付箋や会議は自動で動かない。
- 予定の重なりを許可し、並列表示と枠線で知らせる。
- 未配置への戻し、直前の変更を元に戻す、端末内への保存。
- よく使う付箋をプリセットに保存し、今日の計画へ追加。
- iPhoneのカレンダーを読み込み、表示するカレンダーを選択。
- 左右スワイプで前日・翌日へ移動。全日表示と1・2・4・8倍の拡大表示を切り替え。

## 起動する

macOSと、iOS 17以降をビルドできるXcodeが必要です。

1. このリポジトリを取得し、ios/Yoteikan.xcodeproj をXcodeで開く。
2. Yoteikanスキームと、インストール済みのiPhoneシミュレーターを選ぶ。
3. Runで起動する。

実機ではSigning & CapabilitiesのDevelopment Teamを設定してください。初期版はシミュレーターで検証済みです。実機インストール・TestFlight・App Store配布はまだ行っていません。

## 使い方

1. 右上のカレンダー設定でアクセスを許可し、表示するカレンダーを選ぶ。
2. 右の付箋ゾーンの「プリセット」から今日やる付箋を追加する。その日だけの用事は「つくる」から作成する。
3. 右に貯めた付箋を長押しし、左の時間割へドラッグする。
4. 配置した付箋をタップして選び、右上の↕を上下にドラッグして開始時刻を変更する。付箋全体を長押しして移動する方法も使える。下端のつまみでは長さを変更する。
5. 右の付箋ゾーンへドラッグすると未配置へ戻る。右の付箋をタップすると、その場で予定の詳細に切り替わる。配置済みの付箋はタップで選択し、右の「詳細」で確認できる。
6. 「元に戻す」で直前の変更を戻す。

縦画面は左右の2ゾーンが基本です。右上の「付箋／詳細」でワンタップ切り替えでき、詳細には名前・時刻・所要時間・メモと編集ボタンを表示します。切り替え中もメモの下書きは保持します。横画面など幅に余裕がある場合、付箋表示では中央にメモを追加した3ゾーンになり、詳細表示ではメモを右にまとめます。メモは「メモを保存」で保存します。

日付欄やタイムラインの余白を左へスワイプすると翌日、右へスワイプすると前日へ移動します。「今日」で当日に戻れます。

時間割の上にある＋／−で1・2・4・8倍に拡大・縮小できます。4倍以上では5分刻みの目盛りを表示し、8倍では5分の付箋もつまみで移動・伸縮できます。小さい表示では付箋を時間枠内に収め、入りきらない文字やつまみを省略します。「1日を見る」から戻ると直前の拡大率に戻ります。拡大率はアプリを起動し直すと1倍になります。

右上のパレットで、色と名前を追加・編集できます。色はカラーピッカーまたは6桁のカラーコードで指定します。削除するときは付け替え先を選び、保存すると全日付の付箋・プリセットに反映されます。最後の1色は削除できません。キャンセルで編集を破棄し、「元に戻す」で保存前に戻せます。付箋の内容や時間は保持されます。

右上の時計ボタンから、計画の開始・終了時刻を選べます。初期値は5:00〜24:00で、0:00〜24:00の中から1時間単位で設定し、全日共通で保存します。付箋の移動は5分刻みです。範囲から外れた付箋は元の時刻を保って右のゾーンに「時間外」と表示されます。カレンダーの固定予定は、このアプリから変更できません。

## 技術構成

アプリはSwift / SwiftUI、カレンダーはEventKit、データは端末内のUserDefaultsに保存します。サーバーやアカウントは不要です。スクリーンショット報告ツールはGoの標準ライブラリで実装し、Pythonへの依存はありません。
