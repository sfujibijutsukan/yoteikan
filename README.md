# 予定館 / Yoteikan

朝に1日の予定を組み立てる、iPhone用のタイムボクシングアプリです。カレンダーの固定予定を土台に、「読書・30分」のような付箋を空き時間へ配置します。

<img src="docs/screenshots/39-glass-plan-tab.png" width="300" alt="時間の横棒グラフと、左に時間割・右に付箋がある画面">

## できること

- 内容・所要時間・色・メモ付きの付箋を作成。
- 時間割と付箋置き場で操作。サイドバーは左右を選択可能。横画面では中央に詳細メモを表示。
- 空き時間は、小さな時間表示を添えた横棒グラフで確認。
- 下部の「計画・1日表示・設定」タブで切り替え。時間割上部と旧下部の操作列を削除。
- 色と名前を自由に追加・編集・削除。付箋とプリセットで共通利用。
- 長押しドラッグで配置し、選択後は右上の↕をドラッグして開始時刻を変更。下端のつまみで延長・短縮。
- 予定の上からすぐスワイプすると時間割をスクロール。長押しした場合だけ付箋を移動。
- 変更するのは触っている1枚だけ。ほかの付箋や会議は自動で動かない。
- 予定の重なりを許可し、並列表示と枠線で知らせる。
- 未配置への戻し、直前の変更を元に戻す、端末内への保存。
- プリセットごとに毎日の個数を設定し、その日の付箋置き場へ自動追加。
- iPhoneのカレンダーを読み込み、表示するカレンダーを選択。
- 配置した付箋の開始前に通知。初期値5分前、付箋ごとに0〜1440分前・通知なしを設定。
- 左右スワイプで前日・翌日へ移動。時間割をピンチして1〜8倍に拡大・縮小。
- 下部の「1日表示」タブで1日の時間割を画面いっぱいに表示。

## 起動する

macOSと、iOS 17以降をビルドできるXcodeが必要です。

1. このリポジトリを取得し、ios/Yoteikan.xcodeproj をXcodeで開く。
2. Yoteikanスキームと、インストール済みのiPhoneシミュレーターを選ぶ。
3. Runで起動する。

実機ではSigning & CapabilitiesのDevelopment Teamを設定してください。初期版はシミュレーターで検証済みです。実機インストール・TestFlight・App Store配布はまだ行っていません。

## 使い方

下部の「設定」タブに時間帯、カレンダー、付箋の編集・作成、プリセット、色と名前、サイドバー位置、通知をまとめています。「付箋を編集」では表示中の日の付箋を選んで編集できます。


1. 下部の「設定」→「カレンダー」でアクセスを許可し、表示するカレンダーを選ぶ。
2. 右の付箋ゾーンの「プリセット」で毎日の個数を設定する。設定した枚数が各日の付箋置き場へ自動で追加される。その日だけの用事は「つくる」から作成する。
3. 右に貯めた付箋を長押しし、左の時間割へドラッグする。
4. 配置した付箋をタップして選び、右上の↕を上下にドラッグして開始時刻を変更する。付箋全体を長押しして移動する方法も使える。下端のつまみでは長さを変更する。
5. 右の付箋ゾーンへドラッグすると未配置へ戻る。右の付箋をタップすると、その場で予定の詳細に切り替わる。配置済みの付箋はタップで選択し、右の「詳細」で確認できる。
6. 「設定」→「直前の変更を元に戻す」で変更を戻す。
7. 下部の「1日表示」で時間割全体を確認できる。「計画」で編集画面へ戻る。

全画面の時間割は空き時間を短い帯に折りたたみ、5分などの短い予定もタイトルが読める高さで表示します。予定が多い場合は縦にスクロールできます。時間の長さと表示の高さは比例しません。終日予定は上部、未配置・時間外の件数は下部に表示します。閲覧専用で、「計画」に戻った後も編集画面の倍率・選択状態を保ちます。

プリセットの編集で「毎日の自動追加」を0〜20枚に設定できます（初期値1枚、0枚で停止）。例：歯磨き2枚、ごはん3枚。日付を開いたときやアプリへ戻ったときに、その日にまだ自動追加していない分だけ追加します。配置・編集・削除した付箋を再作成しません。個数を増やすと今日の不足分も追加し、減らしても追加済みの付箋は残します。＋ボタンはその日だけ追加で1枚増やします。既存の付箋をプリセット化した場合、その1枚を当日分として扱います。

下部の「設定」→「サイドバーの位置」で付箋・詳細を左または右に配置できます。初期値は右で、再起動後も選択を保持します。縦画面は左右の2ゾーンが基本です。右上の「付箋／詳細」でワンタップ切り替えでき、詳細には名前・時刻・所要時間・メモと編集ボタンを表示します。切り替え中もメモの下書きは保持します。横画面など幅に余裕がある場合、付箋表示では中央にメモを追加した3ゾーンになり、詳細表示ではメモを右にまとめます。メモは「メモを保存」で保存します。

日付欄やタイムラインの余白を左へスワイプすると翌日、右へスワイプすると前日へ移動します。「今日」で当日に戻れます。

時間割を2本の指で広げると拡大、狭めると縮小します。1〜8倍の間を連続して調整し、指の間の時間帯を基準に表示を保ちます。「1日表示」タブへ切り替えても、計画画面の倍率・選択・メモ下書きを保持します。4倍以上では5分刻みの目盛りを表示し、8倍では5分の付箋もつまみで移動・伸縮できます。小さい表示では付箋を時間枠内に収め、入りきらない文字やつまみを省略します。拡大率はアプリを起動し直すと1倍になります。

「設定」→「付箋の色・名前」で、色と名前を追加・編集できます。色はカラーピッカーまたは6桁のカラーコードで指定します。削除するときは付け替え先を選び、保存すると全日付の付箋・プリセットに反映されます。最後の1色は削除できません。キャンセルで編集を破棄し、「元に戻す」で保存前に戻せます。付箋の内容や時間は保持されます。

「設定」→「計画の時間帯」から、計画の開始・終了時刻を選べます。初期値は5:00〜24:00で、0:00〜24:00の中から1時間単位で設定し、全日共通で保存します。付箋の移動は5分刻みです。範囲から外れた付箋は元の時刻を保って右のゾーンに「時間外」と表示されます。カレンダーの固定予定は、このアプリから変更できません。

下部の「設定」、または付箋編集で通知を許可すると、配置した付箋の通知を予約します。初期値は5分前で、付箋編集から変更できます。未配置・通知時刻を過ぎた付箋は通知しません。直近60件を予約し、起動・編集時に更新します。カレンダーの固定予定はカレンダー側の通知設定を使用します。

## 技術構成

アプリはSwift / SwiftUI、カレンダーはEventKit、データは端末内のUserDefaultsに保存します。サーバーやアカウントは不要です。スクリーンショット報告ツールはGoの標準ライブラリで実装し、Pythonへの依存はありません。
